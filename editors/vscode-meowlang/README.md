# vscode-meowlang

Syntax highlighting for meowlang (`.meow`) files. This is an unpublished,
dev-only VS Code extension — it is not packaged or published to the
Marketplace.

This extension covers syntax highlighting only: keywords, the `yowl`
builtin, strings, numbers, and operators. It does not provide diagnostics,
a language server, or any integration with the meowlang compiler.

## Try it locally

1. Open this folder (`editors/vscode-meowlang`) directly in VS Code (not the
   repo root).
2. Press `F5` to launch an Extension Development Host window.
3. In the new window, open one of the repo's `examples/*.meow` files (e.g.
   `examples/hi.meow`, `examples/strings.meow`, `examples/yowl.meow`) to see
   the highlighting.
